## Flags

- `wrangler.toml` `[vars]` commits storefront values (domain, public Storefront token, Customer Account client id and URL, shop id, sheet id). These are public-facing by design, but they duplicate `.env`; see [[deepening-candidates]].
- `.env.example` lists `SITE_PASSWORD` and `SCOPES`; no reader was found in `app/`, `server.ts`, `vite.config.ts` or `scripts/`. TODO: unknown (may be read by the Shopify CLI).
- Admin API versions differ per file: `2026-04` (`shopifyAdmin.server.ts`), `2025-01` (`newsletter.server.ts`, `workers/price-sync.ts`).
- Omnisend, Klaviyo, Stripe, Supabase, Hostinger: not referenced in this repo's code.
